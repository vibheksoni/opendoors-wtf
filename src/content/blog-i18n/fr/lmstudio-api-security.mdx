## Le problème

LM Studio est une application avec interface graphique qui rend l’exécution de modèles locaux accessible. Elle fournit aussi un **serveur local** qui donne une API compatible OpenAI sur le port **1234**.

Ce serveur vous permet d’utiliser vos modèles depuis d’autres applications ou de les partager sur votre réseau. Comme beaucoup d’outils de développement il préfère la facilité à la sécurité. Vous activez le serveur et cochez "Serve on Local Network" sans pare-feu devant et vous venez d’ouvrir une porte vers internet.

## Ce qui peut mal tourner

Le serveur de LM Studio ne demande aucune authentification par défaut. Si la machine est directement reliée à internet ou si votre routeur redirige le port 1234, un attaquant peut faire ceci.

- **Utiliser vos modèles.** Quelqu’un d’autre utilise votre GPU pour générer du texte ou du code.
- **Vous coûter de l’argent.** De l’inférence continue sur une machine louée c’est une facture pour un travail que vous n’avez jamais demandé.
- **Lire le contexte.** Si la session transporte une conversation précédente ce qu’elle contenait peut être lisible.

## Comment je l’ai trouvé

Je voulais savoir si le design facile avait produit la même exposition accidentelle que je trouve sans arrêt dans d’autres outils. LM Studio a un seul interrupteur dans l’interface qui active le serveur.

Je suis donc allé chercher avec **FOFA** qui est un moteur de recherche du cyberespace.

J’ai cherché les machines avec le port 1234 ouvert et une signature propre à la réponse du serveur de LM Studio. La requête était `port="1234" && body="LM Studio"`.

## Comment protéger votre instance LM Studio

Si vous utilisez la fonction serveur trois étapes vous gardent en sécurité.

### 1. Attachez le serveur à localhost uniquement

Sauf si un autre appareil doit l’atteindre, attachez le serveur à `127.0.0.1` au lieu de `0.0.0.0`. L’interrupteur se trouve dans les réglages du serveur de l’interface.

### 2. Utilisez un pare-feu

Si vous avez vraiment besoin de "Serve on Local Network" laissez le pare-feu de votre système ou votre routeur bloquer le port 1234 depuis l’extérieur et n’autorisez que les adresses locales que vous utilisez.

### 3. Coupez le serveur quand il ne sert pas

Fermez-le quand vous avez terminé. Lancez le serveur local quand vous travaillez et fermez-le après.

## Conclusion

LM Studio installe un serveur de modèles sur votre bureau et cela apporte les mêmes responsabilités réseau que sur une machine cloud. Une seule case à cocher sépare votre GPU d’internet. Regardez sur quoi un interrupteur de serveur écoute vraiment avant de le laisser allumé.
