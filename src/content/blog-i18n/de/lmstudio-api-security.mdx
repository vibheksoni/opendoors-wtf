## Das Problem

LM Studio ist eine Anwendung mit Oberfläche die das Ausführen lokaler Modelle einfach macht. Sie bringt außerdem einen **lokalen Server** mit der dir eine OpenAI-kompatible API auf Port **1234** gibt.

Dieser Server lässt dich deine Modelle aus anderen Anwendungen nutzen oder im lokalen Netz teilen. Wie viele Entwicklungswerkzeuge wählt er die Bequemlichkeit über die Sicherheit. Du schaltest den Server ein und setzt "Serve on Local Network" ohne Firewall davor und hast damit eine Tür ins Internet geöffnet.

## Was schiefgehen kann

Der Server von LM Studio verlangt standardmäßig keine Authentifizierung. Wenn die Maschine direkt am Internet hängt oder dein Router Port 1234 weiterleitet kann ein Angreifer das hier tun.

- **Deine Modelle nutzen.** Jemand anderes nutzt deine GPU für Text oder Code.
- **Dich Geld kosten.** Dauernde Inferenz auf einer gemieteten Maschine ist eine Rechnung für Arbeit die du nie beauftragt hast.
- **Kontext lesen.** Wenn die Sitzung frühere Gespräche mitführt kann lesbar sein was dort stand.

## Wie ich das gefunden habe

Ich wollte wissen ob das einfache Design dieselbe versehentliche Exposition erzeugt die ich ständig in anderen Werkzeugen finde. LM Studio hat einen einzigen Schalter in der Oberfläche der den Server einschaltet.

Also habe ich mit **FOFA** gesucht was eine Suchmaschine für den Cyberraum ist.

Ich habe nach Rechnern mit offenem Port 1234 und einer Signatur gesucht die typisch für die Antwort des LM-Studio-Servers ist. Die Abfrage war `port="1234" && body="LM Studio"`.

Das sind keine leeren Server. Das sind funktionierende API-Endpunkte die auf Prompts antworten.

## So sicherst du deine LM-Studio-Instanz

Wenn du die Server-Funktion nutzt halten dich drei Schritte sicher.

### 1. Nur an localhost binden

Wenn kein anderes Gerät den Server erreichen muss binde ihn an `127.0.0.1` statt an `0.0.0.0`. Der Schalter sitzt in den Servereinstellungen der Oberfläche.

### 2. Firewall nutzen

Wenn du "Serve on Local Network" wirklich brauchst dann lass die Firewall deines Systems oder deinen Router Port 1234 von außen blockieren und erlaube nur die lokalen Adressen die du nutzt.

### 3. Server aus wenn er nicht gebraucht wird

Mach ihn aus wenn du fertig bist. Starte den lokalen Server für die Arbeit und schließe ihn danach.

## Fazit

LM Studio stellt einen Modellserver auf deinen Rechner und das bringt dieselben Netzaufgaben mit die du auf einer Cloud-Maschine hättest. Ein einziges Kontrollkästchen steht zwischen deiner GPU und dem Internet. Schau nach worauf ein Server-Schalter wirklich hört bevor du ihn laufen lässt.
