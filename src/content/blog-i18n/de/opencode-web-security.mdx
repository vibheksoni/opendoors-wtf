## Die bessere Alternative?

Ich benutze in letzter Zeit **OpenCode**, und ehrlich gesagt fühlt es sich in vielerlei Hinsicht wie eine bessere Alternative zu Claude Code an. Es unterstützt mehrere LLM-Anbieter (Ollama, OpenAI, Anthropic usw.), ist Open Source und fühlt sich schneller an. Die Möglichkeit, Modelle spontan zu wechseln, macht es zu einem Kraftpaket für die lokale Entwicklung.

Wie viele Entwicklertools in diesem Bereich bringt es aber einen „Web-UI"-Modus (`opencode web`) mit, der dein CLI in eine browserbasierte Anwendung verwandelt. Das ist praktisch, öffnet aber ein riesiges Sicherheitsloch, wenn du nicht aufpasst.

## Das Risiko

Wenn du `opencode web` ausführst, startet es einen Server. Wenn du ihn an `0.0.0.0` (alle Interfaces) bindest, um von einem anderen Gerät in deinem Netzwerk darauf zuzugreifen, setzt du das gesamte Internet potenziell einer Schwachstelle für **Remote Code Execution (RCE)** aus.

Genau wie bei der Claude Code Web UI, über die ich zuvor geschrieben habe, erlaubt die Weboberfläche von OpenCode dem Nutzer, Befehle auszuführen, Dateien zu bearbeiten und mit der Shell zu interagieren. Ohne Authentifizierung wird jeder, der deine IP-Adresse findet, zum Admin deiner Maschine.

## So sicherst du es ab

Die Entwickler von OpenCode haben tatsächlich einen Sicherheitsmechanismus eingebaut, aber man muss ihn auch nutzen.

### 1. Ein Passwort setzen
Du kannst die Web-UI mit einem Passwort absichern. Dieser einfache Schritt verhindert unbefugten Zugriff.

Führe diesen Befehl aus, bevor du den Webserver startest:
```bash
opencode --set-password <your-strong-password>
```
*Alternativ kannst du die Umgebungsvariable `OPENCODE_SERVER_PASSWORD` setzen.*

### 2. Nicht ins Internet exponieren
Wenn du keinen sehr speziellen Grund hast (und ein VPN/einen Tunnel), leite den OpenCode-Port nicht ins öffentliche Internet weiter. Lass ihn auf `localhost` (`127.0.0.1`) oder strikt innerhalb deines vertrauenswürdigen lokalen Netzwerks (`LAN`).

## Fazit

OpenCode ist ein großartiges Tool, das ich wegen seiner Multi-Modell-Unterstützung und Geschwindigkeit uneingeschränkt empfehle. Aber „leistungsstark" heißt „gefährlich", wenn man die Schutzmechanismen entfernt.

Lass nicht zu, dass dein Coding-Assistent zum Einfallstor für Angreifer wird. Setz ein Passwort.
