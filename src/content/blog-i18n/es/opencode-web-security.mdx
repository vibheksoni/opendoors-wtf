## ¿La mejor alternativa?

He estado usando **OpenCode** últimamente y, la verdad, me parece una alternativa superior a Claude Code en muchos sentidos. Soporta varios proveedores de LLM (Ollama, OpenAI, Anthropic, etc.), es de código abierto y se siente más rápido. La flexibilidad de cambiar de modelo al vuelo lo convierte en una bestia para el desarrollo local.

Sin embargo, como muchas herramientas para desarrolladores de este tipo, incluye un modo "Web UI" (`opencode web`) que convierte tu CLI en una aplicación dentro del navegador. Es genial para la usabilidad, pero abre un enorme agujero de seguridad si no tienes cuidado.

## El riesgo

Cuando ejecutas `opencode web`, se levanta un servidor. Si lo enlazas a `0.0.0.0` (todas las interfaces) para acceder desde otro dispositivo de tu red, potencialmente estás exponiendo una vulnerabilidad de **ejecución remota de código (RCE)** a todo internet.

Igual que la Web UI de Claude Code sobre la que escribí antes, la interfaz web de OpenCode permite al usuario ejecutar comandos, editar archivos e interactuar con la shell. Sin autenticación, cualquiera que encuentre tu dirección IP se convierte en el administrador de tu máquina.

## Cómo asegurarlo

Los desarrolladores de OpenCode sí incluyeron un mecanismo de seguridad, pero hay que usarlo.

### 1. Define una contraseña
Puedes proteger la interfaz web con una contraseña. Este simple paso evita el acceso no autorizado.

Ejecuta este comando antes de iniciar el servidor web:
```bash
opencode --set-password <your-strong-password>
```
*Como alternativa, puedes definir la variable de entorno `OPENCODE_SERVER_PASSWORD`.*

### 2. No lo expongas a internet
A menos que tengas un motivo muy específico (y una VPN o un túnel), no redirijas el puerto de OpenCode a internet público. Mantenlo en `localhost` (`127.0.0.1`) o estrictamente dentro de tu red local de confianza (`LAN`).

## Conclusión

OpenCode es una herramienta increíble que recomiendo mucho por su soporte multimodelo y su velocidad. Pero "potente" significa "peligroso" si le quitas las salvaguardas.

No dejes que tu asistente de programación se convierta en la puerta de entrada de un atacante. Pon una contraseña.
